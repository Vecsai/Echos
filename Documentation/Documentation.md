## 0. Быстрый старт

1. Установите **Ollama**: https://ollama.com/download
2. Скачайте модель:

   ```bash
   ollama pull qwen2.5:7b
   ```

3. Установите зависимости:

   ```bash
   pip install PySide6 requests
   ```

4. Запустите Echos:

   ```bash
   python main.py
   ```

5. Создайте чат (➕) и напишите сообщение.

**Подробная установка** → см. README.md.

## 1. Часто задаваемые вопросы (FAQ)

### Как перенести чаты на другой компьютер?
Используйте экспорт всех чатов в ZIP (меню **Экспорт → ZIP (все чаты)**). На новом компьютере откройте **Настройки → Импорт ZIP-архива** и выберите файл. Программа восстановит чаты, вложения и настройки.

### Почему модель отвечает только «мыслями» без текста?
Это означает, что модель потратила все выделенные токены на внутренние рассуждения (reasoning) и не сгенерировала основной ответ. Решения:
- Увеличьте **Max Tokens** в настройках генерации.
- В системный промпт добавьте: «Отвечай сразу финальным ответом, без размышлений».
- Попробуйте другую модель, менее склонную к длинным размышлениям.

### Как включить тёмную тему?
Нажмите кнопку с иконкой луны/солнца на верхней панели или `Ctrl+T`. Тема сохранится автоматически.

### Можно ли использовать несколько моделей одновременно?
Да, для каждого чата можно указать свою модель через **Параметры генерации** (иконка шестерёнки в области чата). Глобальная модель задаётся в **Настройки → Подключение**.

### Как восстановить удалённый чат из корзины?
Откройте **Корзину** (иконка мусорной корзины на верхней панели), выберите чат и нажмите «Восстановить». Чат вернётся в корень дерева.

### Что делать, если программа не запускается?
- Убедитесь, что установлены все зависимости из `requirements.txt` или команды установки.
- Проверьте логи в папке `logs/app.log`.
- Убедитесь, что Python версии 3.10 или выше (PySide6 требует).
- Попробуйте запустить из консоли, чтобы увидеть ошибку.

### Как обновить Echos до новой версии?
Сохраните резервную копию (ZIP-экспорт), затем замените файлы программы новыми. Ваши данные в папках `chats`, `attachments` и файлах конфигурации останутся нетронутыми, если вы не удаляли их вручную.

### Как сменить пароль на зашифрованном чате?
Правой кнопкой по чату → **«Изменить пароль»**. Введите старый пароль, затем новый. Все вложения этого чата перешифруются.

### Что делать, если LM Studio не отвечает?
Программа предложит кнопки «Повторить» или «Запустить LM Studio». Проверьте, что сервер запущен и модель загружена.

### Что делать, если чат повредился?
Повреждённый файл перемещается в папку `corrupted/` с таймстампом. При старте появится предупреждение. Попробуйте восстановить из `backups/`.

### Что если связь прервалась во время генерации?
Если ответ уже начал приходить — сохранится то, что успело. Иначе появится сообщение «Соединение прервано» с предложением повторить.

### Как настроить Ollama?
1. Установите Ollama: https://ollama.com/download
2. Запустите его — работает в фоне.
3. Скачайте модель: `ollama pull qwen2.5:7b`
4. В Echos: **Настройки → 🦙 Провайдер LLM → Ollama**.
5. Список моделей подтянется автоматически.

### Как работает RAG?
RAG ищет релевантные фрагменты в проиндексированных файлах **гибридным поиском** (FAISS + BM25 + RRF), затем пересортировывает результаты через **ре-ранкер** и подмешивает лучшие в контекст запроса. Подробнее → [раздел 18](#18-база-знаний-rag).

### Как добавить документы в базу знаний?
1. Откройте **Настройки → 📚 База знаний (RAG)**.
2. Включите RAG.
3. Нажмите **📂 Индексируемые папки** → добавьте папку с документами.
4. Нажмите **🔄 Переиндексировать**.
5. Echos автоматически обновляет индекс раз в N минут.

### Что такое MCP и зачем оно?
**MCP (Model Context Protocol)** — набор инструментов, которые модель может вызывать сама: чтение/запись файлов, поиск в интернете. По умолчанию **выключено**. Включается в диалоге **🔧 Инструменты MCP**. Подробнее → [раздел 15](#15-инструменты-mcp).

### Как озвучить ответ модели?
Нажмите кнопку **🔊** в шапке сообщения ассистента. Голос, скорость и громкость настраиваются в **Настройки → 🔊 Озвучивание (TTS)**.

### Как транскрибировать аудио или видео в текст?
Нажмите кнопку **🎤** в панели ввода рядом с 📎. Выберите файл. Требуется `faster-whisper` и `ffmpeg`.

### Что такое скрипты-цепочки?
Инструмент автоматизации: обработка файлов одной командой. Открывается кнопкой **📜** в верхней панели. Команды: `READ`, `PROMPT`, `SAVE`, `LOOP ... END`, `IF ... ELSE ... END`. Подробнее → [раздел 17](#17-скрипты-цепочки).

### Где скачать модели для Ollama?
Официальная библиотека: https://ollama.com/library
Популярные: `qwen2.5:7b`, `llama3.1:8b`, `mistral`, `deepseek-r1:7b`.

### Почему RAG не находит нужное?
Возможные причины:
- Папка с документами **не проиндексирована** — откройте **📂 Индексируемые папки → Переиндексировать**.
- Слишком **высокий порог** релевантности — уменьшите в настройках RAG.
- Формат файла **не поддерживается** — см. список в разделе 18.

## 2. Руководство по резервному копированию и восстановлению

### Что включается в резервную копию?
- Все чаты (файлы из папки `chats`)
- Вложения (папка `attachments`)
- Настройки (`chat_config.json`, `folders.json`, `tree_order.json`, `trash.json`, `prompts.json`, `last_session.json`)

### Ручное создание резервной копии
Используйте **Экспорт → ZIP (все чаты)**. Будет создан ZIP-архив, содержащий все данные, который можно сохранить в надёжном месте.

### Автоматическое резервное копирование
В настройках (**Настройки → Дополнительно**) можно включить автосохранение и задать интервал (по умолчанию 5 минут) и количество хранимых копий (по умолчанию 5). Копии сохраняются в папку `backups`.

### Восстановление из ZIP
Откройте **Настройки → Импорт ZIP-архива** и выберите файл. Программа автоматически заменит текущие данные на данные из архива.

### Если резервная копия повреждена
Попробуйте открыть ZIP вручную (стандартным архиватором) и извлечь файлы в соответствующие папки программы. Если и это не помогает, обратитесь в поддержку.

## 3. Руководство по обновлению

### Проверка текущей версии
Версия отображается в окне «О программе» (вызывается из настроек или `F1`).

### Обновление с сохранением данных
1. Создайте резервную копию (ZIP-экспорт).
2. Закройте программу.
3. Замените все файлы программы (кроме папок `chats`, `attachments`, `plugins`, `backups` и файлов конфигурации, если вы не хотите их перезаписывать) на новые.
4. Запустите программу.

### Совместимость версий
Форматы файлов чатов и конфигурации обратно совместимы. Если выходит крупное обновление с изменением структуры, об этом будет сказано в истории версий.

### Откат к предыдущей версии
Восстановите старые файлы программы из резервной копии и повторите шаги выше.

## 4. Глоссарий терминов

| Термин | Определение |
|--------|-------------|
| **LLM** | (Large Language Model) — большая языковая модель, обученная на больших объёмах текста. |
| **LM Studio** | Приложение для локального запуска LLM с API-сервером. |
| **API** | Интерфейс для взаимодействия с моделью (обычно HTTP-запросы). |
| **RAG** | (Retrieval-Augmented Generation) — генерация, дополненная извлечёнными из базы знаний фрагментами. |
| **Streaming** | Потоковая передача ответа по частям (токенам) в реальном времени. |
| **Reasoning** | Внутренние рассуждения модели, предшествующие ответу (не всегда отображаются). |
| **Max Tokens** | Максимальное количество токенов (слов/символов), которое модель может сгенерировать в ответе. |
| **Temperature** | Параметр генерации, контролирующий случайность. Чем выше, тем более креативные, но менее предсказуемые ответы. |
| **Top P** | Ядерная выборка: ограничивает выбор токенов до тех, чья совокупная вероятность >= P. |
| **Top K** | Ограничивает выбор токенов K наиболее вероятными. |
| **System Prompt** | Системное сообщение, задающее поведение модели. |
| **Ollama** | Приложение для локального запуска LLM с нативным API. |
| **GGUF** | Формат файлов моделей (используется в Ollama и llama.cpp). |
| **num_ctx** | Размер контекста в токенах (параметр Ollama). |
| **MCP** | Model Context Protocol — инструменты для модели (файлы, интернет). |
| **TTS** | Text-to-Speech — озвучивание текста. |
| **STT** | Speech-to-Text — распознавание речи из аудио. |
| **Reranker** | Модель для пересортировки результатов поиска (cross-encoder). |
| **BM25** | Лексический поиск по точным словам (Okapi BM25). |
| **FAISS** | Библиотека векторного поиска (Facebook AI Similarity Search). |
| **RRF** | Reciprocal Rank Fusion — объединение результатов разных поисков. |

## 5. Советы по оптимизации и производительности

### Уменьшение использования памяти
- Закрывайте неиспользуемые чаты (удаление или архивация).
- Отключите RAG, если он не нужен.


### Ускорение генерации
- Используйте более быстрые модели (например, 7B вместо 13B).
- Включите GPU-ускорение в LM Studio.
- Уменьшите `max_tokens` для более коротких ответов.

### Настройка контекста
- `max_context_tokens` должен соответствовать возможностям модели (обычно 4096 или 8192).
- Для длинных диалогов увеличивайте этот параметр, но помните о потреблении памяти.

### RAG без перегрузки

- Держите документы небольшими (до 5000 символов).
- Используйте **индексируемые папки** (Настройки → 📚 RAG → 📂 Индексируемые папки).
- Не индексируйте гигабайты PDF за раз — добавляйте постепенно.
- **Порог релевантности** отсекает нерелевантные чанки — настраивается в коде (`MIN_RERANK_SCORE`).
- Регулярно очищайте индекс от старых документов: удалите папку `RAG_index/` и переиндексируйте.

### Работа на слабых компьютерах

- Используйте лёгкие модели: `llama3.2:3b`, `qwen2.5:3b`, `phi3:mini`.
- Уменьшите **num_ctx** в настройках Ollama (например, до 4096).
- Отключите RAG, если он не нужен (экономит память).
- Отключите TTS/STT (если не используете).
- Сократите количество отображаемых сообщений (ленивая загрузка включена по умолчанию).

## 6. Рекомендации по выбору моделей

### Общие рекомендации
- Для русского языка: модели, обученные на русскоязычных данных (например, Saiga, Vikhr).
- Для генерации кода: CodeLlama, DeepSeek-Coder.
- Для творческих задач: модели с высокой температурой (0.8-1.0).
- Для точных ответов: reasoning-модели (DeepSeek-R1, QwQ).

### Reasoning-модели
Они генерируют длинные размышления перед ответом. Используйте их, когда важна точность, но увеличьте `max_tokens` (до 8192).

### Мультимодальные модели
Поддерживают изображения (например, LLaVA, BakLLaVA). В Echos включите **Мультимодальная модель** в настройках.

### Как узнать поддержку мультимодальности?
Проверьте документацию модели или попробуйте отправить изображение. Echos автоматически определит лимит изображений для известных моделей.

## 7. Раздел для разработчиков

### Архитектура программы

**Основные классы:**

- `MainWindow` — главное окно, управление чатами, настройками, интерфейсом.
- `ChatWorker` — поток для запросов к OpenAI-совместимым API (LM Studio и др.).
- `OllamaWorker` — поток для запросов к нативному API Ollama.
- `OllamaManager` — управление сервером Ollama и моделями.
- `RAGManager` — база знаний (эмбеддинги, FAISS, BM25, ре-ранкер).
- `MCPManager` — диспетчер инструментов MCP.
- `FileSystemTools`, `WebTools` — конкретные инструменты MCP.
- `ScriptRunner` — движок скриптов-цепочек.
- `TranscribeWorker` — фоновое распознавание речи (STT).
- `TTSWorker` — фоновое озвучивание (TTS).
- `MessageWidget` — виджет одного сообщения.
- `ChatMinimapPanel` — мини-карта вопросов.
- `SourcesDialog` — окно источников RAG.
- `ScriptsDialog` — диалог скриптов-цепочек.
- `SettingsDialog` — диалог настроек.
- Плагины загружаются из папки `plugins/`.

### Как собрать из исходников

1. Установите зависимости:

```bash
pip install PySide6 requests sentence-transformers faiss-cpu numpy rank_bm25
pip install pyttsx3 faster-whisper cryptography
pip install python-docx python-pptx PyPDF2 pypdfium2 pdfplumber markdown pygments
pip install matplotlib pillow graphviz
```

2. Для STT дополнительно требуется ffmpeg:

   - Windows: `winget install ffmpeg`
   - Linux: `sudo apt install ffmpeg`

3. Запустите: `python main.py`.


### Структура данных чата
Файл чата — JSON с полями: `title`, `messages`, `folder`, `background_color`, `model`, `params`, `tags` и др.

### Добавление новой функции
- Определите, к какому модулю относится функция.
- Добавьте метод в соответствующий класс.
- Подключите вызов из интерфейса (кнопка, меню, горячая клавиша).
- Проверьте совместимость с существующими настройками.

### Стиль кодирования
- Используйте понятные имена переменных.
- Комментируйте сложные участки.
- Следуйте PEP 8.

### Тестирование и логирование
- Логи пишутся в `logs/app.log`.
- Для отладки используйте `print()` или `self.logger.debug()`.

## 12. Настройка провайдера LLM

Echos поддерживает **два провайдера**: Ollama и LM Studio.

### 🦙 Ollama (рекомендуется)

1. Скачайте и установите [Ollama](https://ollama.com/download).
2. Запустите Ollama — он работает в фоне (иконка в системном трее).
3. Скачайте модель:
   ```bash
   ollama pull qwen2.5:7b
   ```
4. В Echos: **Настройки → 🔀 Провайдер LLM → Ollama**.
5. Хост по умолчанию: `http://localhost:11434`.
6. Модель выберите в выпадающем списке (заполняется автоматически).

**Проверка API:**

```bash
curl http://localhost:11434/api/tags
```

> **Менеджер моделей:** кнопка **📥** в верхней панели Echos — скачивание, удаление, выгрузка из памяти, импорт GGUF.

### 🗄️ LM Studio

1. Скачайте и установите [LM Studio](https://lmstudio.ai/).
2. Загрузите нужную модель через встроенный каталог.
3. Перейдите во вкладку **Server** и нажмите **Start Server**.
4. По умолчанию сервер доступен по адресу `http://localhost:1234/v1`.
5. В Echos: **Настройки → 🔀 Провайдер LLM → Внешний сервер**.
6. Укажите **API Base URL** и **Model** (название модели, как в LM Studio).

**Проверка API:**

```bash
curl http://localhost:1234/v1/models
```

## 15. Инструменты MCP

**MCP (Model Context Protocol)** — набор инструментов, которые модель может вызывать сама. По умолчанию **выключены** — включаются в диалоге **🔧 Инструменты MCP**.

### Файловые инструменты

| Инструмент | Описание |
|---|---|
| `read_file` | Прочитать файл |
| `list_directory` | Список файлов в папке |
| `tree` | Дерево каталогов |
| `search_files` | Поиск файлов по имени (glob) |
| `search_within_files` | Поиск текста внутри файлов |
| `write_file` ⚠ | Создание/перезапись файла |
| `modify_file` ⚠ | Замена текста в файле |
| `move_file` ⚠ | Перемещение/переименование |
| `delete_file` ⚠ | Удаление |

### Безопасность

- **Белый список папок** — модель работает только внутри разрешённых.
- **Подтверждение опасных действий** — по умолчанию Echos спрашивает разрешение (рекомендуется оставить).
- **Лог** — все действия пишутся в `logs/mcp.log`.
- **Лимиты** — максимальный размер файла, максимальное количество результатов поиска.

### 🌐 Интернет-поиск

- **Белый список доменов** в `Sites.txt` — модель работает только с разрешёнными сайтами.
- Wildcard: `*.github.com` — все поддомены.
- Кэширование страниц (TTL настраивается).
- **Защита от промпт-инъекций** — подозрительные фразы в тексте страницы заменяются на `[УДАЛЕНО]`.

**Инструменты:** `web_search` (DuckDuckGo), `fetch_url` (загрузка страницы).

## 16. Озвучивание и распознавание речи

### 🔊 TTS — озвучивание ответов

- Библиотека: `pyttsx3` (или `py3-tts` для Python 3.13+).
- Кнопка **🔊/🔇** в шапке каждого сообщения ассистента.
- В настройках: выбор голоса (все системные), скорость, громкость, тест.
- Markdown-разметка вырезается перед озвучкой.

**Установка:**

```bash
pip install pyttsx3
# для Windows также:
pip install pywin32
python -m pywin32_postinstall -install
```

### 🎤 STT — транскрибация файлов

- Библиотека: `faster-whisper` (полностью оффлайн после первой загрузки).
- Кнопка **🎤** рядом с 📎 — выбрать файл → распознать.
- Форматы: `mp3`, `wav`, `m4a`, `ogg`, `flac`, `aac`, `mp4`, `mkv`, `mov`, `avi`, `webm`.
- Модели: `tiny`, `base`, `small` (рекомендуется), `medium`, `large-v3`.
- **Модель выгружается из памяти после работы.**

**Установка:**

```bash
pip install faster-whisper
# + ffmpeg:
winget install ffmpeg        # Windows
sudo apt install ffmpeg      # Linux
```

## 17. Скрипты-цепочки

Инструмент автоматической обработки файлов одной командой. Открывается кнопкой **📜** в верхней панели.

### Команды

| Команда | Что делает |
|---|---|
| `READ путь` | Прочитать файл (txt, pdf, docx, py, md и др.) |
| `PROMPT инструкция` | Отправить запрос модели |
| `SAVE путь` | Сохранить результат в файл |
| `LOOP маска ... END` | Цикл по файлам в папке |
| `IF условие ... ELSE ... END` | Ветвление |

### Переменные

- `{{file}}`, `{{file.name}}`, `{{file.stem}}`, `{{file.ext}}`, `{{file.dir}}`
- `{{index}}` — номер файла в цикле
- `{{date}}`, `{{time}}`, `{{timestamp}}`

### Условия в `IF`

- `содержит "текст"`
- `не содержит "текст"`
- `начинается с "текст"`
- `заканчивается на "текст"`
- `длина больше N`
- `длина меньше N`

### Примеры

**Массовый перевод:**

```
LOOP D:\texts\*.txt
READ {{file}}
PROMPT Переведи на английский, сохрани стиль
SAVE D:\texts_en\{{file.name}}
END
```

**Сортировка логов:**

```
LOOP D:\logs\*.log
READ {{file}}
PROMPT Определи уровень (CRITICAL/WARNING/OK)
IF содержит "CRITICAL"
SAVE D:\reports\critical\{{file.stem}}.md
ELSE
SAVE D:\reports\ok\{{file.stem}}.md
END
END
```

> Полная справка — кнопка **❓ Справка** в диалоге скриптов.

## 18. База знаний (RAG)

RAG позволяет модели отвечать, опираясь на **ваши документы**.

### Индексируемые папки

- **Настройки → 📚 База знаний (RAG) → 📂 Индексируемые папки**.
- Указывайте **любые папки** на диске.
- Автоотслеживание изменений (интервал настраивается).
- Поддерживаемые форматы: `txt`, `md`, `py`, `json`, `csv`, `html`, `log`, `pdf`, `docx`, `pptx`.
- **Извлечение таблиц** из PDF/DOCX/PPTX — сохраняются как Markdown.

### Как работает поиск

1. Вы задаёте вопрос.
2. **Гибридный поиск:**
   - **FAISS** — по смыслу (`paraphrase-multilingual-MiniLM-L12-v2`)
   - **BM25** — по точным словам
   - **RRF** — объединение результатов
3. **Ре-ранкер** `bge-reranker-base` пересортировывает топ кандидатов.
4. Лучшие чанки подмешиваются в контекст.

### Источники

- Кнопка **📚 Источники (N)** под ответом ассистента.
- Клик → диалог: имя файла, фрагмент, релевантность.
- **Кликабельные `[1]`, `[2]`** в тексте — открывают источник.
- Кнопки: **📂 Открыть источник**, **📋 Скопировать путь**.
- Поддерживаются **веб-источники** (при интернет-поиске).

### Оптимизация

- Не индексируйте гигабайты PDF за раз.
- При замедлении — переиндексируйте (удалить `RAG_index/`, добавить папку заново).
- При ошибках поиска — уменьшите порог релевантности.
